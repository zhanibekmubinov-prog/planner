## 2026-09-03 · сессия 4 · Cowork (desktop) — v0.5 MCP-коннектор для Claude
**Сделано**
- **MCP-коннектор** по образцу CIS Platform: `POST /mcp` (Streamable HTTP, stateless JSON-RPC: initialize / ping / tools/list / tools/call), OAuth 2.0 с Dynamic Client Registration + PKCE S256, метаданные RFC 8414/9728. Файлы: `backend/app/routers/mcp_oauth.py`, `backend/app/routers/mcp.py`, `backend/app/mcp_tools.py`; модели `McpClient / McpPendingAuth / McpAuthCode / McpToken` (в базе только SHA-256 хеши; access 8 ч, refresh 30 дн. с ротацией), миграция `f1a5b6c7d8e9`.
- Вход в коннектор — через Microsoft: `/oauth/authorize` → Entra (state `mcp:<key>`, тот же `/api/auth/callback`) → страница согласия `/oauth/consent` в стиле «Инженерный журнал» → код → токены. Без `MS_*` (локально) страница согласия принимает служебный `API_TOKEN`. Служебный токен также принимается как Bearer на `/mcp` (владелец).
- **19 инструментов**: сводки (`get_overview`, `list_directions`, `get_direction_summary`, `list_tasks`, `get_task`, `list_people`, `get_person_report`, `get_team_report`) и запись (`create_direction`, `update_direction`, `create_task` — сразу с направлениями/исполнителями/сроком/проверкой/напоминанием, `update_task`, `set_task_status`, `add_task_note`, `delegate_task`, `update_delegation`, `add_reminder`, `create_person`, `add_tool`). Сущности ищутся по id или части названия; при неоднозначности — ошибка со списком кандидатов. Статусы принимаются по-русски. Отчёт по человеку: доля выполненных, доля вовремя (по `activity_log`), средний срок, просрочки, пропущенные проверки, отчёты исполнителя.
- Инструкции сервера (initialize.instructions) учат Claude: «запиши / поручи / напомни / сводка / как дела у …» = команды планнеру, даты переводить в ISO самому, подтверждать одной фразой, удаления нет. Текущее время и день недели передаются в инструкциях.
- `docs/MCP_CONNECTOR.md` — инструкция для сотрудников + памятка для Personal preferences в Claude + техчасть. `backend/test_mcp.py` — прогон OAuth-флоу и всех инструментов на sqlite (два пользователя: владелец и исполнитель) — проходит.
- `main.py`: версия API 0.5.0, роутеры `mcp_oauth` и `mcp` подключены без общего `require_token` (своя проверка Bearer). `config.py`: `PUBLIC_URL` (необязательно).

**Решения владельца**
- Вход в коннектор — как в CIS Platform: каждый сотрудник подключает от своего Microsoft-аккаунта и видит своё + порученное.
- Удалять через Claude нельзя — только «выполнено», пауза, архив, закрытие поручения.
- Распознавание «запиши/поручи» — инструкции сервера + памятка для настроек Claude.

**Итог:** миграция применена, `test_mcp.py` → ALL OK (в `requirements.txt` добавлен `python-multipart`), задеплоено, метаданные OAuth в проде корректны, владелец подключил коннектор в claude.ai — работает. Коллеги подключаются сами своей учёткой @cis.kz.
**Идея на потом:** роли/видимость для руководителей (видеть поручения друг друга / всю команду) — отдельное решение по правам.
**Осталось** — проверить голосом с телефона. Идеи: кнопка «Подключить Claude» в профиле фронта; инструменты для майндмапов; отчёт «успешность» на Карте направлений.
