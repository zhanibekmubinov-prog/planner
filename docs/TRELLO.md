# Переезд из Trello в Планнер

Для коллег, у которых есть доски в Trello и уже подключён коннектор Планнера в Claude
(проверить: в чате Claude спросить «что у меня в планнере» — должен ответить по вашим задачам).

**Что получится.** Одна доска Trello → один проект в Планнере внутри вашего направления.
Карточки станут задачами, колонки — статусами, чеклисты перенесутся с галочками, сроки — в дедлайны,
участники карточек — в поручения. Метки, комментарии и ссылка на исходную карточку попадут в описание
задачи, чтобы ничего не потерялось.

Времени: 2 минуты на выгрузку, затем 5–15 минут работы Claude на доску — в зависимости от размера.

---

## Шаг 1. Выгрузить доску из Trello

1. Открыть доску в браузере (не в телефоне).
2. Справа сверху нажать **«⋯ Показать меню»** → **«Ещё»** → **«Печать, экспорт и общий доступ»**
   (в английском интерфейсе: *More → Print, export, and share*).
3. Выбрать **«Экспорт в формате JSON»** (*Export as JSON*).
4. Откроется страница с текстом или сразу скачается файл. Если открылась страница — нажать **Ctrl+S**
   и сохранить как файл `.json` (имя любое, лучше по названию доски).

Одна доска — один файл. Экспорт в JSON бесплатный; экспорт в CSV в Trello только на платном тарифе,
он нам и не нужен.

Файл может быть большим (несколько мегабайт) — это нормально, там хранится вся история доски.

## Шаг 2. Отдать файл Claude

Открыть **новый чат** в Claude (в приложении или на claude.ai — там, где подключён коннектор Планнера),
прикрепить файл скрепкой и вставить текст ниже. Одна доска — один чат.

```
Это экспорт моей доски Trello. Перенеси её в Планнер.

1. Сначала разбери файл и покажи мне план, ничего не создавая:
   название доски, колонки и сколько карточек в каждой, какая колонка станет
   каким статусом (бэклог / в работе / ждём / выполнено), сколько карточек
   архивных (их и закрытые колонки пропускаем). Спроси меня, в какое
   направление положить доску и как назвать проект. Жди моего «да».

2. После «да»: создай проект и перенеси карточки пачками через
   create_tasks_bulk — сначала с dry_run, потом запись. Для каждой карточки:
   название; описание, а в конец описания — метки, комментарии с датами и
   ссылку на карточку Trello; статус по колонке; срок из due; чеклист с
   галочками как в Trello; участников карточки — в поручения (если человека
   нет в справочнике — добавь).

3. В конце скажи, сколько задач создано, сколько пропущено, и что проверить.
```

Дальше Claude покажет план и задаст два вопроса — направление и название проекта. Проверьте
сопоставление колонок со статусами: у нас их четыре, а колонок в Trello может быть больше.
Обычно так: «Надо сделать», «Идеи», «Бэклог» → **бэклог**; «В работе», «Делаю» → **в работе**;
«Ждём», «На согласовании», «Заблокировано» → **ждём**; «Готово», «Сделано» → **выполнено**.
Если что-то не так — просто напишите, как надо, и потом «да».

## Шаг 3. Проверить в Планнере

Открыть Планнер → своё направление → карта проектов → новый проект. Посмотреть пару карточек:
статус, срок, чеклист, описание. Если у карточки в Trello был участник, в Планнере это поручение
этому человеку — ему придёт уведомление «Вам поручено», предупредите коллег заранее.

---

## Если чат оборвался на середине

Ничего страшного. Открыть новый чат, снова прикрепить тот же файл и написать:

```
Продолжи перенос этой доски Trello в проект «<название проекта>» направления
«<направление>». Часть задач уже создана — Планнер сам пропускает задачи,
чьи названия уже есть в проекте, поэтому просто прогони все карточки ещё раз.
```

Дубли не появятся: коннектор пропускает задачи с уже существующим в этом проекте названием.

## Если получилось не то

Удалять через Claude нельзя — это защита от случайных команд. Зайдите в Планнер, нажмите правой кнопкой
на проект → **«Удалить»** — проект уйдёт в корзину (30 дней можно восстановить), и повторите перенос.

## Что не переносится

- Вложенные файлы — только ссылками на Trello (сами файлы остаются там, пока доска существует).
- Метки как отдельная сущность — у нас их нет, они дописываются в описание («Метки: Срочно, Насосы»).
- Комментарии старше ~1000 последних действий по доске — Trello не выгружает их в JSON.
- Обложки карточек, голоса, пользовательские поля Premium, история перемещений между колонками.

## Советы

- Большая доска (больше 150 карточек) — попросите Claude переносить по одной колонке за раз.
- Если у доски нет смысла как у проекта (просто список дел), скажите Claude положить задачи
  прямо в направление, без проекта.
- Просроченные сроки из Trello переносятся как есть — такие задачи сразу окажутся просроченными.
  Хотите чистый старт — попросите Claude не переносить сроки у выполненных карточек или вовсе убрать
  старые даты.
